# Cairn support and updates

This is the public release, update, and issue-tracking repository for Cairn.
The proprietary Cairn source code is maintained separately and is not included
here.

- [Download Cairn for macOS](https://updates.p10q.com/cairn/Cairn-latest.dmg)
- [Buy the $19.99 beta license](https://store.p10q.com/l/cairn)
- [Support](https://p10q.com/cairn/support/)
- [Security reports](https://p10q.com/cairn/security/)
- [Release notes](cairn/CHANGELOG.md)

GitHub issues are public. Do not include license keys, terminal contents,
credentials, pairing codes, or other private information.

The macOS app is beta software. The beta license is a $19.99 one-time purchase
and remains valid without a subscription. Pricing for new customers is
expected to become $19.99 per month after beta.
