# Cairn support and updates

This is the public release, update, and issue-tracking repository for Cairn.
Cairn for macOS is free to download and use, but remains proprietary. Its
source code is maintained separately and is not included here.

- [Download Cairn for macOS](https://updates.p10q.com/cairn/Cairn-latest.dmg)
- [Cairn Remote for iPhone and iPad — $19.99](https://apps.apple.com/us/app/cairn-remote/id6781109004)
- [Support](https://p10q.com/cairn/support/)
- [Security reports](https://p10q.com/cairn/security/)
- [Release notes](cairn/CHANGELOG.md)

GitHub issues are public. Do not include terminal contents, credentials,
pairing codes, purchase details, or other private information.

Cairn Remote is a separate $19.99 App Store purchase for iPhone and iPad.
