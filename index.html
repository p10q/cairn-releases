Cairn

This is the software-update server for Cairn, the native macOS terminal. It hosts the Sparkle appcast and release downloads; the app checks it automatically for updates.

Cairn for macOS is free to download and use. It remains proprietary software.

Cairn Remote is a separate $19.99 App Store purchase for iPhone and iPad.
