# Cairn compatibility files

`Cairn-latest.dmg` is the stable public macOS download. `CHANGELOG.md` is the
release history. `appcast.xml` remains a compatibility bridge for Cairn
versions released before 2.5.0.

Current app builds use the signed Sparkle channel configured in the private
Cairn source repository. Versioned artifacts and deltas live in the opaque
Sparkle directory; this directory exposes only the stable latest download and
compatibility files.
